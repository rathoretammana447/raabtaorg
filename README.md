## 🌱 About Rabta

Rabta (राबता) is a grassroots educational initiative based in **Derabassi, Punjab, India**, founded by **Tammana Rathore**. It provides free educational support, guidance, and practical life-skills development for underprivileged children.

Rabta's approach goes beyond textbooks and examinations. It aims to strengthen academic foundations while helping children build confidence, communication skills, practical abilities, and awareness of future opportunities.

## 🎯 Vision

> “A future where every child has access to education, skills and the opportunity to build a better life.”

### Short-term priorities
- Increase the number of students supported

### Medium-term priorities

- Create structured skill-development programmes
